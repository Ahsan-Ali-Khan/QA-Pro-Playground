    Category: DOM Remove/Insert • Expand-Collapse • Stale Elements
    What is Selenium WebDriver?−
    Selenium WebDriver is a browser automation framework that allows scripts to control a browser directly via native browser support.
    What is the Page Object Model?+
    POM is a design pattern that creates an object repository for web UI elements, improving test maintenance and readability.
    What is an explicit wait?+
    An explicit wait tells WebDriver to wait for a certain condition before proceeding — e.g., WebDriverWait(driver, 10).until(EC.visibility_of_element).
    How does Shadow DOM affect locators?+
    Shadow DOM encapsulates elements so standard driver.find_element cannot reach inside unless you use expand_shadow_element or JS executor.
